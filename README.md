## What it does

`main.py` writes a single one-line joke about office life — the sort of line
you send a colleague after a meeting that should have been an email — to
`/output/entry.txt`. The program is deterministic and uses no network.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
